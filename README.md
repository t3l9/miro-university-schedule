# Miro University Schedule API

FastAPI-сервис, который превращает доску Miro в красивое интерактивное расписание университета.
Управляется через REST API со Swagger UI «из коробки».

## Что выглядит на доске

```
┌──────────────────────────────────────────────────────────────┐
│   РАСПИСАНИЕ НА НЕДЕЛЮ                                       │
│   Понедельник — Суббота · 7 пар в день                       │
├──────────────────────────────────────────────────────────────┤
│      │ Пн │ Вт │ Ср │ Чт │ Пт │ Сб │   ← тёмные шапки
│      │ ━━ │ ━━ │ ━━ │ ━━ │ ━━ │ ━━ │   ← цветной акцент под каждой
├──────┼────┼────┼────┼────┼────┼────┤
│09:00 │ЛЕК │I·пр│пус │ПРА │пус │пус │   ← карточка пары или placeholder
│до    │... │╌╌╌╌│    │... │    │    │   ← пунктир делит ячейку: I сверху / II снизу
│10:30 │    │II·л│    │    │    │    │   ← числитель (нечёт) / знаменатель (чёт)
├──────┼────┼────┼────┼────┼────┼────┤
│ ...  ...                              │
```

**Чётность недели (числитель / знаменатель):**
Каждую ячейку можно занять либо одной парой «на каждую неделю» (на всю ячейку),
либо двумя половинами — **нечётная (I, числитель)** сверху и **чётная (II, знаменатель)**
снизу, разделёнными тонкой линией. У половинных карточек в углу — бейдж `I` / `II`.

**Палитра** — современный «design system» стиль:
- Шапки в едином тёмно-синем тоне (`#1E293B`)
- Цветные акцентные полоски под каждым днём (синий, бирюзовый, зелёный, жёлтый, розовый, фиолетовый)
- Карточки пар с мягкой пастельной заливкой и насыщенной цветной рамкой под тип занятия
- Светлые placeholder-плашки в пустых ячейках, чтобы сетка читалась с первого взгляда

**Структура карточки пары:**
```
┌──────────────────────────┐
│ ЛЕКЦИЯ                   │  ← мелким, цветом акцента
│                          │
│ Математический анализ    │  ← крупно, жирно
│ ━━━━━━━━━                │  ← тонкий разделитель
│ 🏛  очно                  │
│ 👤  Иванов И.И.           │
└──────────────────────────┘
```

## Возможности

- Сетка **понедельник — суббота**, 7 временных слотов (09:00–21:10)
- Цветовая кодировка по типу занятия (лекция/практика/лаба/семинар/экзамен/консультация)
- Карточка пары: дисциплина, тип, формат (очно/дистант/гибрид), ФИО преподавателя
- **Локальное хранилище** (`storage.json`) маппит наши пары на ID объектов Miro,
  чтобы редактировать и удалять именно конкретную пару
- Автоматический ретрай сетевых сбоев (полезно при SSL-инспекции антивирусами)
- Атомарность: если init упал на середине — фрейм откатывается

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env   # заполни MIRO_ACCESS_TOKEN и MIRO_BOARD_ID
python run.py
```

Swagger UI: **http://localhost:5000/docs**

## Где взять токен и Board ID

1. **Token:** Miro → *Profile settings* → *Your apps* → создать своё приложение → *Install app and get OAuth token*.
   Нужны scope'ы `boards:read`, `boards:write`.
2. **Board ID:** открой доску, скопируй ID из URL: `https://miro.com/app/board/<BOARD_ID>/`.

## API

| Метод | Путь | Что делает |
|---|---|---|
| `GET`    | `/api/health`             | Проверка живости |
| `GET`    | `/api/meta`               | Справочник: дни, слоты, типы, форматы, **чётности**, цвета |
| `POST`   | `/api/board/init`         | Создать всю сетку на доске |
| `DELETE` | `/api/board`              | Снести расписание (`?keep_frame=1` чтобы оставить шапку) |
| `GET`    | `/api/schedule`           | **Расписание сеткой** (дни × слоты × чётность) из storage |
| `POST`   | `/api/board/sync`         | **Считать расписание С ДОСКИ** после ручных перетаскиваний |
| `GET`    | `/api/lessons`            | Список пар (`?day=Понедельник`, `?week=нечётная` для фильтра) |
| `POST`   | `/api/lessons`            | Создать пару (поле `week`: `обе`/`нечётная`/`чётная`) |
| `GET`    | `/api/lessons/{id}`       | Получить пару |
| `PATCH`  | `/api/lessons/{id}`       | Изменить пару (кроме day/slot/week) |
| `POST`   | `/api/lessons/{id}/move`  | Перенести пару (другая ячейка и/или чётность недели) |
| `DELETE` | `/api/lessons/{id}`       | Удалить пару |

### Чтение данных с доски — `POST /api/board/sync`

Сценарий: расписание разложено через API, **затем карточки правились вручную
прямо в Miro** — и нужно вернуть актуальное состояние обратно в систему.

`sync` читает фактические позиции карточек на доске, по «якорям» (шапкам дней и
меткам времени) калибрует координатную сетку, сопоставляет каждую карточку
ближайшей ячейке день × слот и обновляет `storage`. Карточки на доске при этом
**не двигаются** — пересобираются только плейсхолдеры опустевших/занятых ячеек.

| Параметр | Что делает |
|---|---|
| `?preview=true`      | Сухой прогон: показать, что считалось, ничего не записывая |
| `?detect_week=true`  | Заодно определить числитель/знаменатель по верх/низ половине ячейки |

Чтобы перетаскивание работало «как карточка целиком», все элементы карточки
склеиваются в Miro-группу при создании.

## Архитектура

```
app/
├── config.py        # настройки, дни, слоты, дизайн-палитра, геометрия
├── storage.py       # JSON-файл с маппингом lesson <-> miro_item_id
├── miro_client.py   # тонкий клиент Miro REST API + retry-сессия
├── schedule.py      # геометрия раскладки, рендеринг карточек, CRUD
└── api.py           # FastAPI + Pydantic + Swagger
run.py               # запуск через uvicorn
```

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| `MIRO_ACCESS_TOKEN не задан` | Создай `.env` или `set MIRO_ACCESS_TOKEN=...` в той же сессии |
| `401 Unauthorized` | Токен просрочен — пересоздать в Miro |
| `403 Forbidden` | Не те scope'ы у токена (нужны `boards:read`+`boards:write`) |
| `404 Board not found` | Не тот Board ID, или доска чужой команды |
| `SSL: UNEXPECTED_EOF` | Антивирус с SSL-инспекцией или корпоративный прокси режут трафик. Отключи AV или попробуй другую сеть |
| 500 без JSON | Смотри traceback в окне uvicorn |
| `уже инициализирована` при init | Удали `storage.json` и фрейм с доски, потом снова `init` |

## Цветовая кодировка типов

| Тип занятия    | Заливка | Акцент |
|---|---|---|
| лекция         | бледно-синяя    | синий (`#2563EB`)    |
| практика       | бледно-зелёная  | зелёный (`#059669`)  |
| лабораторная   | бледно-оранж.   | оранжевый (`#EA580C`)|
| семинар        | бледно-розовая  | розовый (`#DB2777`)  |
| экзамен        | бледно-красная  | красный (`#DC2626`)  |
| консультация   | бледно-сиренев. | фиолет. (`#7C3AED`)  |

Все цвета можно менять в `app/config.py` → `COLORS_BY_TYPE`.
